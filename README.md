
# CAA900 Capstone Project

A serverless e-commerce website using various Amazon Web Services including Amplify, Lambda functions, DynamoDB, API Gateway, Cognito, Amazon SES, and more.

Rexony is a fictional brand that sells home decor and lifestyle necessities.

Link to Site: https://main.dijcvcdvudbc2.amplifyapp.com/

CI/CD pipeline automated through Github.

## Features

- Account Creation
- Guest Checkout
- Order, Stripe payment, and confirmation email
- Admin dashboard
- Reviewing System
